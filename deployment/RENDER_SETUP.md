# Render.com Backend Setup for LishFind

## Step 1: Prepare Repository

1. Make sure your code is pushed to GitHub repository
2. Ensure `backend/` folder contains all necessary files:
   - `main.py` (entry point)
   - `requirements.txt` (dependencies)
   - `render.yaml` (deployment config)
   - `.env.render` (environment template)

## Step 2: Create Render Account

1. Go to [render.com](https://render.com)
2. Sign up with your GitHub account
3. Authorize Render to access your repositories

## Step 3: Deploy Backend Service

1. Click "New +" → "Web Service"
2. Connect your GitHub repository: `wearelish/Lish-finds`
3. Configure the service:

### Basic Settings
- **Name**: `lishfind-backend`
- **Region**: Oregon (or closest to you)
- **Branch**: `main`
- **Root Directory**: `backend`
- **Runtime**: Python 3
- **Build Command**: `pip install -r requirements.txt`
- **Start Command**: `python main.py`

### Plan
- Select **Starter (Free)** plan

## Step 4: Set Environment Variables

In the Render dashboard, go to your service → Environment tab and add:

```
ENVIRONMENT=production
DEBUG=false
HOST=0.0.0.0
PORT=8000
SECRET_KEY=<auto-generated-by-render>
DATABASE_URL=<your-supabase-connection-string>
CORS_ORIGINS=https://lishfind-frontend.vercel.app,http://localhost:3000
ALLOWED_HOSTS=lishfind-backend.onrender.com
AI_PROVIDER=disabled
REDIS_URL=
EMAIL_ENABLED=false
STORAGE_TYPE=local
MAPS_PROVIDER=nominatim
RATE_LIMIT_PER_MINUTE=30
LOG_LEVEL=INFO
```

**Important**: Replace `<your-supabase-connection-string>` with the actual DATABASE_URL from Supabase.

## Step 5: Deploy

1. Click "Create Web Service"
2. Render will automatically:
   - Clone your repository
   - Install dependencies
   - Start your application
3. Wait for deployment to complete (5-10 minutes)

## Step 6: Verify Deployment

1. Once deployed, you'll get a URL like: `https://lishfind-backend.onrender.com`
2. Test these endpoints:
   - `https://lishfind-backend.onrender.com/health` (should return health status)
   - `https://lishfind-backend.onrender.com/` (should return API info)
   - `https://lishfind-backend.onrender.com/docs` (API documentation)

## Important Notes

### Free Tier Limitations
- **Sleep Mode**: Service sleeps after 15 minutes of inactivity
- **Build Time**: Up to 15 minutes build time
- **Memory**: 512MB RAM limit
- **Bandwidth**: 100GB/month
- **Storage**: Temporary filesystem only

### Optimization for Free Tier
- AI features disabled to avoid API costs
- Redis disabled (no persistent caching)
- Reduced rate limits
- Smaller connection pools

### Troubleshooting

**Build Fails**:
- Check `requirements.txt` for compatibility issues
- Verify Python version (Render uses Python 3.11 by default)

**Service Won't Start**:
- Check environment variables are set correctly
- Verify DATABASE_URL is valid
- Check logs in Render dashboard

**Database Connection Issues**:
- Ensure Supabase allows connections from Render IPs
- Verify DATABASE_URL format is correct
- Check if PostGIS extension is enabled in Supabase

**CORS Errors**:
- Update CORS_ORIGINS to include your frontend domain
- Ensure both HTTP and HTTPS variants are included if needed

## Logs and Monitoring

- View logs in Render dashboard → Logs tab
- Health check endpoint: `/health`
- Service automatically restarts on failure
