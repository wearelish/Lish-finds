# LishFind Deployment Guide
*Complete setup for free hosting with Vercel + Render + Supabase*

## 🎯 Overview

This guide will help you deploy LishFind to free hosting services:
- **Frontend**: Vercel (static hosting)
- **Backend**: Render (API hosting) 
- **Database**: Supabase (PostgreSQL with PostGIS)

**Total time**: ~30 minutes  
**Total cost**: $0/month (free tiers)

## 📋 Prerequisites

1. **GitHub Account** - Your code should be in the `wearelish/Lish-finds` repository
2. **Accounts needed**:
   - [Supabase](https://supabase.com) - Database
   - [Render](https://render.com) - Backend API
   - [Vercel](https://vercel.com) - Frontend hosting

## 🚀 Deployment Steps

### Step 1: Deploy Database (Supabase)

1. **Create Supabase Project**:
   - Go to [supabase.com](https://supabase.com) and sign up
   - Create new project: `lishfind-database`
   - Choose region closest to you
   - Generate strong database password (save it!)

2. **Enable PostGIS**:
   - Go to Database → Extensions
   - Enable `postgis` extension
   - Wait for installation to complete

3. **Run Initial Schema**:
   - Go to SQL Editor
   - Copy and paste the schema from `deployment/SUPABASE_SETUP.md`
   - Execute the SQL to create tables and sample data

4. **Get Connection String**:
   - Go to Settings → Database
   - Copy the connection string (looks like):
     ```
     postgresql://postgres:[password]@db.[project-ref].supabase.co:5432/postgres
     ```
   - **Save this** - you'll need it for the backend

✅ **Checkpoint**: Your database should be ready with sample data

### Step 2: Deploy Backend (Render)

1. **Create Render Account**:
   - Go to [render.com](https://render.com)
   - Sign up with your GitHub account
   - Authorize access to your repositories

2. **Deploy Backend Service**:
   - Click "New +" → "Web Service"
   - Connect to `wearelish/Lish-finds` repository
   - Configure:
     - **Name**: `lishfind-backend`
     - **Region**: Oregon (or closest)
     - **Root Directory**: `backend`
     - **Runtime**: Python 3
     - **Build Command**: `pip install -r requirements.txt`
     - **Start Command**: `python main.py`
     - **Plan**: Starter (Free)

3. **Set Environment Variables**:
   ```
   ENVIRONMENT=production
   DEBUG=false
   HOST=0.0.0.0
   PORT=8000
   SECRET_KEY=<auto-generated-by-render>
   DATABASE_URL=<your-supabase-connection-string>
   CORS_ORIGINS=https://lishfind-frontend.vercel.app,http://localhost:3000
   ALLOWED_HOSTS=lishfind-backend.onrender.com
   AI_PROVIDER=disabled
   REDIS_URL=
   EMAIL_ENABLED=false
   STORAGE_TYPE=local
   MAPS_PROVIDER=nominatim
   RATE_LIMIT_PER_MINUTE=30
   LOG_LEVEL=INFO
   ```

4. **Deploy**:
   - Click "Create Web Service"
   - Wait for deployment (5-10 minutes)
   - You'll get a URL like: `https://lishfind-backend.onrender.com`

✅ **Checkpoint**: Test at `https://lishfind-backend.onrender.com/health`

### Step 3: Deploy Frontend (Vercel)

1. **Create Vercel Account**:
   - Go to [vercel.com](https://vercel.com)
   - Sign up with your GitHub account

2. **Deploy Frontend**:
   - Click "New Project"
   - Import `wearelish/Lish-finds`
   - Configure:
     - **Framework Preset**: Other
     - **Root Directory**: `.` (root)
     - **Build Command**: (leave empty)
     - **Output Directory**: (leave empty)

3. **Set Environment Variables**:
   ```
   BACKEND_URL=https://lishfind-backend.onrender.com
   ```

4. **Deploy**:
   - Click "Deploy"
   - Wait for deployment (~2 minutes)
   - You'll get a URL like: `https://lishfind-frontend.vercel.app`

✅ **Checkpoint**: Your frontend should load with animations

### Step 4: Update CORS Settings

1. **Update Backend CORS**:
   - Go to your Render service dashboard
   - Update the `CORS_ORIGINS` environment variable:
     ```
     CORS_ORIGINS=https://lishfind-frontend.vercel.app,https://your-custom-domain.com,http://localhost:3000
     ```
   - Restart the service

2. **Test Connection**:
   - Open your Vercel frontend URL
   - Click "Try a search" button
   - Check browser console for connection status

✅ **Checkpoint**: Frontend should connect to backend successfully

## 🔧 Configuration Details

### Environment Variables Reference

| Variable | Service | Value | Description |
|----------|---------|-------|-------------|
| `DATABASE_URL` | Render | Supabase connection string | PostgreSQL database |
| `SECRET_KEY` | Render | Auto-generated | JWT signing key |
| `CORS_ORIGINS` | Render | Frontend URLs | Allowed origins |
| `AI_PROVIDER` | Render | `disabled` | Free tier setting |
| `BACKEND_URL` | Vercel | Render backend URL | API endpoint |

### Free Tier Limitations

**Supabase Free Tier**:
- 500MB database storage
- 2GB bandwidth/month
- PostGIS included

**Render Free Tier**:
- 512MB RAM
- Sleeps after 15 minutes of inactivity
- 750 hours/month

**Vercel Free Tier**:
- 100GB bandwidth/month
- Unlimited deployments
- Custom domains (1 per project)

## 🚨 Troubleshooting

### Backend Won't Start
- Check environment variables are set correctly
- Verify DATABASE_URL format
- Check Render logs for detailed errors

### CORS Errors
- Update `CORS_ORIGINS` to include your frontend domain
- Restart Render service after changes

### Database Connection Issues
- Verify Supabase database is running
- Check if PostGIS extension is enabled
- Test database connection in Supabase SQL editor

### Frontend Shows "Connection Failed"
- Check if backend URL is correct in Vercel environment variables
- Verify backend is awake (free tier sleeps after 15 minutes)
- Check browser network tab for specific error details
